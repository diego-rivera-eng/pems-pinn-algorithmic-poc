# Configuraciones congeladas

Esta carpeta agrupa configuraciones de modelos, políticas finales, contratos de
arquitectura y manifiestos de protocolo. La estructura sigue el eje
`familia/protocolo/objetivo/fase` cuando aplica.

Los archivos son evidencia de campañas terminadas. No modifique un artefacto
marcado `FROZEN`; para una nueva campaña cree una versión nueva y registre su
linaje.
