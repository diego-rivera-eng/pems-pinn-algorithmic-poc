# Resultados

`frozen/` contiene tablas, auditorías, figuras, reportes y estados inmutables de las
campañas canónicas. Se preservan métricas por semilla, métricas de ensamble,
predicciones, complejidad, huellas computacionales, resultados de optimización
y contratos de acceso a TEST.

Los archivos resumen creados para navegación son:

- `frozen/interpolative/metrics_summary.csv` — Tabla 32 del manuscrito.
- `frozen/walk_forward/metrics_summary.csv` — Tabla 34 del manuscrito.
- `frozen/computational_benchmark/model_size_summary.csv` — Tabla 33.

Estos resúmenes no reemplazan la evidencia primaria por campaña. La procedencia
exacta está en `manifests/book_evidence_map.csv` y
`manifests/migration_manifest.csv`.
